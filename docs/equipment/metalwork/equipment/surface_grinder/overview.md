# Overview

The surface grinder, affectionately known as Herbert, is in the fabrication room off to the right of the main metalwork room.

We believe the model is a Herbert Junior Surface Grinder version 1.
The version 2 and above include an automatic oiling system.
Also it was adapted for use with metric bearings which makes the mounting system for the grinding wheel a little different than normal.

  * [Herbert-Junior-Grinder-Parts-Manual](../../../../instruction_manuals/Herbert-Junior-Grinder-Parts-Manual.pdf)

This is an expensive precision machine on permanent loan and built in the 1950's, so please respect that and be gentle.
The surface grinder is a finishing tool to perform finishing operations on metals and stone to provide a perfectly flat finish.
This allows metalworkers to make things parallel and all sorts of other neat stuff. A surface grinder, like any other power tool can be dangerous if used incorrectly. 

## Inductions

Before being inducted on the surface grinder please request an induction on the Metal Milling machine first
Any questions, ask in the metalwork group and they will be happy to help. The surface grinder requires an in person induction to use. 

We are currently developing the RA and inductions.
